# Research Agent 验收对照

依据：[Research Agent 主线 PRD](research-agent-track-prd.md) 第 5 节（RA-01—RA-08）与第 10 节（RA-AC-01—RA-AC-08）、[补充说明](research-agent-clarifications.md) comment4。数字均来自[实验结果](results.md)，样例来自[研究成果样例](research/)，都由运行记录生成。

系统有两版配置，两版都完整运行和报告。第一版的经验只有文字记录；第二版的经验另外保存完整的已验证程序，新任务先由程序复验，学习运行在已知最佳上继续超越。第一版的 C 对照是修改的依据，第二版的最终验收用实现前封存的 D 批。

## 1. 功能需求

| 编号 | 实现 | 在哪里看 |
| --- | --- | --- |
| RA-01 研究任务定义 | 任务包冻结研究问题（契约）、初始程序、开发/最终数据、目标；运行创建时冻结预算、工具、模型、评测器与复用规则，写入配置指纹 | 运行页“研究任务 · 运行开始前固定”；研究记录“研究任务”节；`backend/tasks/lock.json` |
| RA-02 证据管理 | 取证工具（cProfile）与每次评测都有记录 ID；评测反馈只给测得事实（状态、加速比、失败类别、公开反例）；模型解释单独标为“未验证” | 运行页决策账本；经验卡片“测得事实 / 模型解释”分栏 |
| RA-03 假设与实验 | 每个实验执行前写下目的、预期结果和验证方法：模型候选由模型写，复用的程序由程序依据经验记录写明来源、原实测结果与条件差异；评测后由程序按当时目标判定：支持、部分支持、反驳、未能检验 | 运行页“假设与实验”（复用实验带“复用”标记）；研究记录同名表；结果第 4 节统计 |
| RA-04 反馈驱动调度 | 每步状态包含上一结果、已试方向、剩余预算；复验结果决定是否调用模型，学习运行据此提高目标；连续未达标按固定规则升级到 GPT；每个决定都记录依据 | 决策账本“→ 下一步”；“提高本次目标”步骤写明依据；升级步骤写明触发条件 |
| RA-05 候选比较 | 只有通过且全部样本快于基线的候选才能替换最佳；复用的程序与模型候选同一规则；失败与退化候选保留代码和评测 | 运行页候选加速比条（↺ = 复用）；`report.json` 的 `best_rule` |
| RA-06 最终独立评价 | 循环结束后冻结最佳候选，在隐藏最终数据上测一次；最终数据不进容器、不进检索、不回流 | 运行页第四个状态“最终测试达到目标”；研究记录“独立最终测试” |
| RA-07 成果复现 | `export-run --bundle` 导出研究记录、最佳程序、全部候选、原始模型调用、报告与复核脚本；`experiment.sh` 重跑整条流水线 | [研究成果样例](research/)；`reproduce.sh` |
| RA-08 系统对照 | 同一 Agent、同一配置，只换经验快照（v0 无经验 vs 学习后的快照），每批 6 任务 × 3 次，交替串行；第二版 B 开发对照 + D 封存留出，第一版 B + C | 对照页；[实验结果](results.md) 第 1—3 节 |

## 2. 验收条件

| 编号 | 证据 | 结论 |
| --- | --- | --- |
| RA-AC-01 问题、目标、约束、预算、基线事前确定且可复现 | 任务包按哈希锁定；每次运行保存配置指纹（模型、提示词、动作模式、预算、评测器、沙箱镜像、检索与复用规则）；基线在同一次评测中交替测得；D 批在第二版实现之前提交并锁定（`d542906`），对照前没有任何运行触及 | 满足 |
| RA-AC-02 关键实验有事前假设和验证方法，结论引用实际证据 | 全部正式运行共 395 个实验，其中复用实验 138 个、模型实验 257 个；全部在执行前写下目的、预期与验证方法，其中 380 个另写了明确假设；判定引用评测 ID（结果第 4 节） | 满足 |
| RA-AC-03 至少一个可核验的反馈驱动决策 | [A-01](research/run-20261113T161733-7c5a/README.md)：c1 实测 0.90×，假设被反驳 → 修正后输出格式错误 → 按规则升级 → GPT 读到具体反馈，1.45× 得到支持。第二版学习中，复验结果达标 → 程序把目标提高 5% → 模型以最佳复用程序为父候选提出超越方案（见研究成果样例）。后续模型假设点名引用同一运行早先候选 50/142（下限） | 满足 |
| RA-AC-04 错误、退化、证据不足如实记录 | 判定由程序给出，不由模型自评：被反驳 97 个、未能检验 27 个；复验不适用的程序同样判为被反驳并写回经验；第一版 A-05 结论“无改进” | 满足 |
| RA-AC-05 最终独立评价，通过与未通过都报告 | 开发数据达标但最终测试未满足严格规则的运行如实记为未达标（第一版 B 1 次、C 2 次，第二版 B 2 次、D 1 次） | 满足 |
| RA-AC-06 总成本覆盖完整过程，预算不足时正确结束 | 每次模型调用记录用量与估算费用，未知记“未知”不记 0；复验的评测时间计入循环时长；学习阶段成本沿快照链单列（第二版两轮 $0.455）；预算耗尽后交付当前最佳、不再为总结调用模型 | 满足 |
| RA-AC-07 从固定输入重跑最佳方案与评价 | A-01 样例的 `reproduce.sh` 复核：最终数据正确、1.44×（记录值 1.4367×）；第二版 D-01 样例复核：正确、1.4473×（记录值 1.4481×）；环境（沙箱镜像 ID、容器 Python 版本、Docker 服务信息、资源额度）随运行保存；`scripts/experiment.sh` 重跑两轮学习与 B、D 对照 | 满足 |
| RA-AC-08 主张经验有效时提供完整对照 | 第二版 B、D 与第一版 B、C 各 36 次运行全部计入，每个对照配置一致性检查通过；学习成本单列；不利结果（第一版 C 的加速比下降、第二版 B 上费用持平且集中在 B-05）同样报告 | 满足 |

## 3. 系统本身的评估（comment4）

| 问题 | 第二版 · D 封存留出（v0 无经验 → v19） | 第一版 · C 最终留出（v0 → v6） |
| --- | --- | --- |
| 研究成果：带来多少提升 | 达标 15/18 → 18/18；最终加速比中位数 1.20× → 1.73× | 达标 16/18 → 16/18；最终加速比中位数 1.41× → 1.29× |
| 用了多长时间 | 单次研究循环时长中位数 53s → 27s；总耗时 1782s → 669s | 84s → 50s；2000s → 1886s |
| 花了多少 Token | 模型请求 52 → 0 次（中位数 2.5 → 0）；输入 153,890 → 0，输出 41,101 → 0 | 请求中位数 3 → 1；输入 151,880 → 232,044，输出 45,728 → 30,532 |
| 云端模型成本 | 升级到 GPT 7 → 0 次，费用 $0.376 → $0.000；学习阶段另计 $0.455 | 升级 11 → 5 次，费用 $0.372 → $0.292；学习另计 $0.149 |
| 能否自我迭代并改进 | 18/18 次运行没有调用任何模型，由复验的已验证程序直接达标；A 批两轮学习各任务的最终加速比逐轮提高（第 1 轮 A-01 1.19× / A-02 1.41× / A-03 1.09× / A-04 1.40× / A-05 1.24× / A-06 1.77×；第 2 轮 A-01 1.45× / A-02 2.03× / A-03 1.24× / A-04 1.58× / A-05 1.69× / A-06 1.96×） | 经验让请求和升级减少，但停在更低的加速比——这一发现推动了第二版 |

第二版 B 开发对照（v0 → v19）：达标 16/18 → 18/18，最终加速比中位数 1.28× → 1.56×，请求中位数 2.5 → 0，循环时长中位数 63s → 25s，GPT 费用 $0.249 → $0.262；新经验一侧的费用全部来自 B-05（$0.262，v0 在该任务上 $0.141）。

## 4. 未做与后置

- 专用决策模型对照（PRD §9 可选项）：未实现，按 PRD 后置。
- 多个独立 Agent、开放式文献检索、跨领域研究：未实现，首版只做一个研究循环和一个软件优化任务族。
- 复验未达标时，复验过的程序都留在提示词里，GPT 单次请求更长（第二版 B 的 B-05：平均输入 3.4k → 11.4k token）；只保留最佳一个程序是已知的下一步改进，未在本次冻结配置中修改。
- 对照页的“过程中最佳开发验证结果”在每次运行的运行页查看，对照页汇总最终验收结果。
