## desktop：Decisions路由短批

2026-11-14 调整实验范围至约一小时窗口后，本批新建独立账本执行四组各 1 次。每轮研究循环统一上限 360 秒、20 个全部 HTTP 请求、10 候选，允许主动 `finish`；`final`、启动和导出不计入研究循环预算。均使用完整反馈、`adaptive` 与空 `v0` 经验库，由 `small` 起步并允许单向升级至 `large`。

- small：托管Qwen3.8-27B，thinking=false，输出上限8192。
- large：gpt-6.1-sol，xhigh，输出上限32000。
- Decisions：真实Decisions API的gpt-6-luna；路由和生成请求共用20次预算。

| 组合（动作/模型路由） | final分数 | 相对c0提升 | 实际总耗时 | small / large请求 | Decisions请求 | 候选dev通过/提出 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| LLM / rule | 139736 | +5.970% | 392.039秒 | 3 / 6 | 0 | 5/5 |
| Decisions / rule | 139972 | +6.149% | 389.380秒 | 2 / 5 | 7 | 7/7 |
| LLM / Decisions | 139559 | +5.836% | 389.913秒 | 7 / 4 | 8 | 6/6 |
| Decisions / Decisions | 132540 | +0.513% | 112.910秒 | 6 / 0 | 13 | 6/6 |

共同final c0=131864。四组的研究循环都未超过360秒；总耗时包含final。实际批次为北京时间16:49:44–17:11:08，共21分24秒。

本次仅动作 Decisions 得分最高，比路由基线高 236 分；仅模型 Decisions 比基线低 177 分。双 Decisions 全程 `small`、主动提前结束，耗时较短但得分提升较小。每组各仅一次样本，以上描述该轮单次行为与质量—时间—成本关系。

共61次HTTP请求：18次small、15次large（含1次timeout）、28次Decisions。24个提出的候选全部通过dev，另有4个c0；四个交付候选分别通过全部15个final用例。

原 900 秒长批在中途终止后独立保留：`baseline` 最终分数 139950，`action` 轮按 `user_stopped` 结束且未执行 `final`，其余 10 项未启动，数据与上述 360 秒短批分别归档。

## Mac 端探索结果

文件审计确认完成四项 OpenAI-only 探索，使用固定 `gpt-6.1-sol`，每项 180 秒 / 5 请求 / 3 候选上限，每题仅 2 个 dev 用例，关闭 final 评测，于高宿主机负载环境下作为独立的 dev-only 非正式探索单列记录。

| 任务 | 模式 | 文件审计的最佳正确候选dev加速比 |
| --- | --- | ---: |
| convolve | feedback | 1.298578× |
| convolve | independent | 2.669288× |
| PageRank | feedback | 25.041935× |
| PageRank | independent | 23.051415× |

逐轮报告、调用记录和 ledger 确认 12/12 模型调用成功；输入 34,240 tokens、输出 26,717 tokens（其中 reasoning 18,884 tokens 已包含在输出中，不重复计费）。16 次评测均为高负载下的 dev 评测，未包含 held-out final 验证；累计 slot 耗时 567.385 秒。

远端 LM Studio 的三本失败账本受系统代理影响合计记录 19 次 HTTP 503 调用。绕过代理后，一次 Qwen 直连请求运行 120.19 秒，输入 2327、输出 2047 tokens（其中 reasoning 1707），因输出上限以 `incomplete/length` 结束；四本账本合计产出 0 个完整协议模型候选。

另有 1 份人工根据完整 reasoning 与截断可见代码进行语义重建（并移除未使用 import、重命名局部变量）的候选，其 2-case dev 检查结果为 2/2 正确、1.225486×（candidate max 0.000856825 秒 < baseline min 0.000881116 秒）。该产物已明确标记 `eligible_as_model_generated_candidate=false` 与 `formal_results_eligible=false`，单独归档且不纳入模型自主成功率或正式结果。

前期准备工作（环境、初版校准、GC 诊断及历史 runner，详见[历史准备材料](native-formal-20261114/algotune/README.md)）按原有分支记录归档，对应 27 轮原计划未启动。
