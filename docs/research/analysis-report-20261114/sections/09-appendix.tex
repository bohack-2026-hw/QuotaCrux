\subsection{版本与数据来源}
固定 Qwen 执行源码为 \texttt{990f598}，路由与 Mac 最终执行源码为 \texttt{912b20a}。desktop 分析来自仓库快照 \texttt{cd9cc4f} 的归档。报告重算 439 个输入文件，保存对应 SHA256；另外核验三批完整清单的 356、114、54 个条目，共 524 项。

本报告的脚本校验覆盖归档完整性、调用账本重算与候选哈希核对；完整重现评测另需原始 benchmark 数据与容器运行环境。

\subsection{Mac 归档校验与恢复记录}
Mac 归档以提交 \texttt{5962203} 为准。早期导出器中的正则脱敏规则曾误删代码方括号，归档在修复导出逻辑后依据原始运行报告与 SHA256 校验码恢复了 25 份受损候选源码（恢复记录见 \texttt{recovery.json}），其余脱敏标记与截断响应保持原样。经核验，189 个清单条目、24 份候选、12 份最优程序及 16 份任务源码哈希一致，53 份归档程序通过 Python 语法检查，完整检验结果记录于 \texttt{mac-analysis.json}（状态为 \texttt{verified\_archive}）。

\subsection{远端本地模型尝试与人工补全记录}
归档另收录远端 LM Studio（\texttt{qwen3.8-27b-uncensored-mlx}）的预备测试记录：经代理发起的前三组请求累计出现 19 次 HTTP 503（12、6、1 次）；直连单次请求耗时 120.193 秒，在输出达到 2047 tokens（含 1707 reasoning tokens，输入 2327 tokens）上限后截断并记为 \texttt{incomplete}。随附的一份基于截断推理输出的人工补全验证程序（两例开发检查加速比 1.225486$\times$，参考与候选中位耗时分别为 0.947241 和 0.772951 ms）在元数据中单独标为人工协助产物。上述记录均未计入第 \ref{sec:mac} 节的模型自动化评测。
