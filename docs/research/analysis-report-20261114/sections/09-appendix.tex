\subsection{版本与数据来源}
固定 Qwen 执行源码为 \texttt{990f598}，路由与 Mac 最终执行源码为 \texttt{912b20a}。desktop 分析来自仓库快照 \texttt{cd9cc4f} 的归档。报告重算 439 个输入文件，保存对应 SHA256；另外核验三批完整清单的 356、114、54 个条目，共 524 项。

本轮复核覆盖归档文件、调用用量、候选哈希与运行记录。重新执行完整裁判还需要原 benchmark 输入及运行环境。样本配置包括固定模型各组三次重复、路由各组一次、Mac 每题两个开发用例；本报告据此给出逐次观测、过程分析和后续可检验的假设。

\subsection{Mac 补交材料的复核状态}
Mac 的 \texttt{fcf186c} 提交补齐了比较文件、报告、调用、计时及候选导出。数值账本已交叉核对；188 个导出清单条目与文件匹配。候选一致性复核发现，16 个 OpenAI 候选文件中 10 个与运行时记录哈希不符，6 个出现语法错误。原因是导出器的 IP 脱敏规则误处理了代码下标中的方括号。已请求修复导出规则并从原始数据重新导出。

报告的 Mac 数值来自运行记录，算法描述结合候选声明与记录中的实现信息。代码文件的重导出状态、计时样本、人工协助分类和来源哈希集中保存在 \texttt{mac-analysis.json}。

\subsection{远端 Qwen 与人工协助记录}
远端 LM Studio 运行 \texttt{qwen3.8-27b-uncensored-mlx}。代理配置导致前三个失败批次分别产生 12、6、1 次 HTTP 503，共 19 次；绕过代理后的直连请求耗时 120.193 秒，返回 2327 输入、2047 输出 tokens，其中 1707 为 reasoning，响应因长度上限截断，记录为 incomplete。

另有一份人工语义重建程序：作者根据模型可见推理补全实现，整理导入并调整变量名。它在独立两例开发检查中取得 1.225486 倍加速，参考与候选中位时间分别为 0.947241 和 0.772951 ms。该程序在元数据中归为人工协助产物。
