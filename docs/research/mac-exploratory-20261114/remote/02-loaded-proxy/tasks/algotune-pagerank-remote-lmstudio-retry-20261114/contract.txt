Optimize AlgoTune pagerank. Submit a Python module exposing solve(problem). NumPy, SciPy and NetworkX are available. The initial code defines the exact input and output interface. Every result must pass the pinned upstream numerical checker; NaN/Inf and incorrect shapes are rejected. Do not read stdin or write stdout. Timing covers the solve call, excluding imports and serialization. Every measurement uses fresh candidate globals and a fresh input object.

Input is {'adjacency_list': list[list[int]]}; row i lists the destinations of outgoing edges from node i, with nodes indexed 0 to n-1. Return {'pagerank_scores': list[float | int]} in node-index order, with exactly n finite non-negative values. A NumPy array is not accepted in place of that list. The reference is networkx.pagerank with alpha=0.85, max_iter=100, tol=1e-6. The judge compares scores to that reference using numpy.allclose(rtol=1e-5, atol=1e-8); for n>1 it also checks that the sum is 1 with math.isclose(rel_tol=1e-5, abs_tol=1e-8). The reference convergence tolerance and the judge comparison tolerance are separate parameters.
